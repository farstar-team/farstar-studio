# Farstar Studio

صفحهٔ شخصی راست‌به‌چپ، بدون وابستگی به ابزار ساخت. برای پیش‌نمایش `index.html` را باز کنید یا `python -m http.server` اجرا کنید.

برای افزودن نمونه‌کار، بلوک `<article class="project">` در `index.html` را کپی و عنوان، توضیح، نشانی و تصویر آن را تغییر دهید. راه‌های تماس، مهارت‌ها و متن‌ها نیز در همین فایل قابل ویرایش هستند. فونت ساحل در پوشه `assets` با مجوز همراه قرار دارد.
